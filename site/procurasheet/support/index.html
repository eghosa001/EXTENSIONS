Help with ProcuraSheet

Quick answers for importing supplier files, fixing blocked rows and creating a clean purchase-order CSV.

Which files can ProcuraSheet read?

CSV, TSV, TXT and common XLSX workbooks up to 25 MB. ProcuraSheet reads the selected worksheet and can detect a header row even when supplier notes appear above the table.

Why is a row marked “Blocked”?

Every exported line needs a Shopify SKU or barcode and a positive whole-number quantity. ProcuraSheet also blocks duplicate identifiers, invalid cost/tax values and SKU/barcode conflicts when a catalog is loaded.

Does ProcuraSheet need my Shopify password?

No. The extension does not ask for Shopify credentials. It creates a CSV for you to import through Shopify's Purchase Orders screen.

Where are my saved supplier mappings stored?

In your browser's extension storage. Version 1.0 does not upload supplier files, catalog exports or saved mappings to a ProcuraSheet server.

My supplier spreadsheet uses unusual columns. What should I do?

Choose the correct header row, then use the mapping controls to select which source column represents SKU, barcode, supplier SKU, quantity, cost and tax. Save the supplier template when the mapping is correct.

Should I review the CSV in Shopify?

Yes. ProcuraSheet validates the source data, but you should still review Shopify's matched products, quantities, costs and taxes before saving or using a purchase order.

Found a bug or need help?

Use the issue form to report the problem. Please include the browser version, what type of supplier file you used, and the exact error message. Do not upload confidential supplier files publicly.
