# 09 — LinkPack

## Product promise
Extract every useful link from a webpage, selection or group of tabs, clean and deduplicate them, then export them in the format the user actually needs.

## Platform
Chrome + Microsoft Edge extension (Manifest V3).

## Customer
Researchers, marketers, SEO professionals, developers, recruiters, content teams and power users.

## MVP
- Extract links from current page.
- Extract links from selected content.
- Optional extraction from selected/open tabs.
- Internal vs external grouping.
- Domain grouping.
- Dedupe.
- Filters for images, documents, email links and ordinary URLs.
- Search/filter results.
- Copy as plain URLs, Markdown or CSV.
- No account required.

## Differentiation
The core competitor category proves demand, but LinkPack should focus on export quality and multi-tab workflows instead of becoming a scraper platform.

## Demand evidence
Link Grabber on the Chrome Web Store currently shows about 200,000 users.

Reference:
https://chromewebstore.google.com/detail/link-grabber/caodelkhipncidmoebgbbeemedohcdma

## Monetization
- Free: current-page extraction and basic copy.
- Pro target: $3–$6/month or low-cost lifetime licence.
- Pro: multi-tab extraction, advanced filters, presets, batch export and saved recipes.

## Validation
Measure:
1. Extract actions per weekly active user.
2. Most-used output format.
3. Multi-tab demand.
4. Repeat domains/workflows.
5. Whether advanced filters create willingness to pay.

## Do not overbuild
No automated crawling, proxy infrastructure, scraping-as-a-service, lead enrichment or cloud database in V1.
