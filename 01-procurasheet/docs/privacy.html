Privacy Policy — ProcuraSheet v1.1.3

Effective date: 7 October 2026

ProcuraSheet v1.1.3 is a local-first browser extension whose single purpose is to convert supplier spreadsheet line items into a validated CSV that can be imported into Shopify Purchase Orders.

Supplier and order data

Supplier CSV/XLSX files, optional Shopify product exports, column mappings, normalized purchase-order rows, SKU corrections and generated CSV files are processed locally in the browser. ProcuraSheet does not upload those files or order rows to its billing service.

Local storage

Browser extension storage may contain supplier names and saved column templates, Business-plan Supplier SKU → Shopify SKU mappings, monthly export usage counters, cached plan entitlement and a paid-plan license token if you activate one. Settings backups exclude the license token and subscription state.

Paid-plan verification

If you choose a paid plan, the ProcuraSheet website collects the billing email you enter and sends it to Paystack to start subscription checkout. Card details are entered on Paystack-hosted pages. When you activate or manage a paid license, the extension requests optional access to https://procurasheet-billing.onrender.com/* and sends only the signed license token for subscription verification or billing management.

Permissions

The extension requires only the storage permission at install time. Optional access to the fixed billing origin is requested only for paid-license activation, subscription-status verification and billing-portal access. ProcuraSheet does not request broad website access.

Analytics, advertising and remote code

Version 1.1.3 contains no advertising SDK and no remote executable code. Executable extension logic is packaged with the extension. Billing responses contain subscription data only.

Shopify

When you click Open Shopify Admin, ProcuraSheet opens https://admin.shopify.com/. The extension does not send generated purchase-order data to Shopify automatically and never asks for your Shopify password. ProcuraSheet is independent software and is not affiliated with, endorsed by, or sponsored by Shopify Inc.

Payments

Payment processing is performed by Paystack. Paystack may process billing information under its own privacy terms when you use hosted checkout or the billing portal.

Contact

For support or privacy questions, use the project issue tracker.
