SUPPORT & FAQ

Get back to quoting quickly.

Contractor Clipper is intentionally small and local-first. These answers cover the most common workflow and troubleshooting questions.

Why didn't a product scan fill every field?

Supplier sites expose product data differently. Contractor Clipper prefers structured product data, then falls back to page metadata and visible product elements. Review the detected values before saving and type any missing field manually.

Does Contractor Clipper watch every site I visit?

No. It does not run a background browsing tracker and does not request broad host access. Product-page reading happens after you invoke the extension and click Scan current product.

Where are my projects stored?

Projects, supplier memory and branding are stored in Chrome local extension storage. Use Backup in the quote workspace to keep a JSON copy of important work.

Why are cost and markup missing from my printed quote?

That is intentional. Cost and markup are internal estimating fields and are hidden from the client-facing print/PDF output.

What does Export Excel create?

It creates SpreadsheetML XML, a structured spreadsheet format that Microsoft Excel and compatible spreadsheet applications can open. CSV export is also available.

How do I report a supplier site that extracts badly?

Include the supplier product URL, which fields were wrong or missing, and the expected result in a support issue. Do not include private client details in a public issue.

REPORT A PROBLEM

Open a support issue.

For a reproducible bug, feature request or supplier-site extraction problem, use the project's public GitHub issue tracker. Remove client names, addresses and other private information before posting.
