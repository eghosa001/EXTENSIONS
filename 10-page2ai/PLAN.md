# 10 — Page2AI

## Product promise
Turn any webpage or selected content into clean, structured Markdown that is immediately useful as AI context, notes or documentation.

## Platform
Chrome + Microsoft Edge extension (Manifest V3).

## Customer
Developers, researchers, students, writers, analysts and heavy AI-assistant users.

## MVP
- Convert current page to clean Markdown.
- Convert selected content only.
- Remove navigation, ads and obvious boilerplate.
- Preserve headings, lists, tables, links, quotes and code blocks.
- Include title and source URL.
- Copy to clipboard.
- Download .md.
- "AI-ready" mode that strips low-value clutter and images.
- Approximate token/word count.
- Local-first; no AI API required for the core workflow.

## Differentiation
Do not sell generic HTML-to-Markdown. Sell fast preparation of reliable source context for AI tools, documentation and research.

## Demand evidence
Current Chrome Web Store examples show meaningful adoption:
- MarkSnip — about 30,000 users.
- Webpage to Markdown — about 30,000 users.
- Copy as Markdown — about 40,000 users.

## Monetization
- Free: page/selection conversion.
- Pro target: $4–$8/month.
- Pro: combine selected tabs, batch export, reusable templates, front matter and large research bundles.
- Consider lifetime pricing during validation.

## Validation
Measure:
1. Copy vs download usage.
2. Percentage using AI-ready mode.
3. Demand for multi-tab bundles.
4. Repeat weekly usage.
5. Maximum context size users commonly prepare.

## Do not overbuild
No hosted RAG system, vector database, built-in chatbot or subscription AI model in V1.
