# Store listing draft

## Name
Contractor Clipper

## Short description
Clip products from supplier websites into contractor quotes and estimates in seconds.

## Detailed description
Contractor Clipper helps contractors, interior designers, installers, tradespeople, and estimators turn web products into project quotes without copying details by hand.

Open a product or supplier page, scan it with the extension, review the detected product name, SKU, price, image, and source link, then add it to a project quote. Adjust quantity, markup, labour, discount, and tax from the quote workspace. Export line items to CSV or print the quote to PDF.

Version 0.1.0 is local-first: project and quote data remain in browser extension storage.

### Core features
- Product-page detection using structured data and page metadata
- Manual review before saving
- Multiple quote projects
- Quantity and markup controls
- Labour, discount, and tax calculations
- CSV export
- Printable/PDF-ready estimate
- No account required
- No backend required
