# Privacy policy — Supplier Sheet → Shopify PO

Version 0.1.0 processes supplier files and optional Shopify catalog exports locally in the user's browser.

The extension does not upload supplier files, purchase-order data, product catalogs or saved supplier mappings to an external server. Saved supplier templates and SKU mappings use browser extension storage.

The extension requests only browser storage permission. It does not request access to browsing history, page contents, email, payments or Shopify credentials.

If future versions add accounts, analytics, cloud sync, AI extraction or Shopify OAuth, this policy must be updated before release.
