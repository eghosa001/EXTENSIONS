# Store listing draft

## Name
Supplier Sheet → Shopify PO

## Short description
Convert messy supplier Excel/CSV sheets into Shopify Purchase Order CSVs without retyping.

## Detailed description
Supplier Sheet → Shopify PO is a local-first converter for Shopify merchants and inventory buyers.

Upload a supplier spreadsheet, confirm which columns represent SKU, barcode, supplier SKU, quantity, cost and tax, review any rows that need attention, then export a Shopify-ready purchase-order CSV.

The extension can remember each supplier's column layout and learn Supplier SKU → Shopify SKU corrections, so recurring orders get faster over time. You can also load a Shopify product export locally to help backfill SKU matches by barcode.

Files stay in the browser in version 0.1.0. No account, backend or Shopify password is required.

### Key features
- CSV, TSV and XLSX input
- Automatic column detection
- Saved supplier templates
- Supplier SKU → Shopify SKU memory
- Optional Shopify catalog matching
- Strict validation before export
- Shopify PO CSV export
- Review CSV for blocked/warning rows
